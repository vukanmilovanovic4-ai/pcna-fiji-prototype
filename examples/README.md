# Synthetic teaching example

All three rows in `synthetic_annotations.tsv` are fabricated. IDs, coordinates, slices and labels do not refer to the research acquisition. The columns illustrate one record per nucleus, pattern separate from eligibility, and explicit uncertainty/exclusion reasons.

This is a simplified table, not a complete checkpoint or a macro-loadable file. No image, ROI ZIP or interactive demonstration is included. The synthetic rows must not be used to assess classifier or detector performance.
